# Feature Lead Summary: Companies' Views

## 1 Introduction

This summary reports the companies' views on link failure detection and beam reporting submitted to this meeting, and gives the moderator's proposals for agreement.

## 2 Companies' Views

Avelin [1] proposes an acknowledgement timeout of 419 ms, to detect a failed link within one report period.

According to Borealis [2], the acknowledgement timeout should be 213 ms.

Corvane [3] argues that the beam report should carry the 21 strongest beams.

Delmar [4] supports a beam report period of 898 ms.

Estrella [5] opposes a beam report period of 397 ms, citing the reporting overhead.

## 3 Moderator's Proposals

Proposal 3.1: The acknowledgement timeout is 716 ms.

Proposal 3.2: The beam report period is 214 ms.
