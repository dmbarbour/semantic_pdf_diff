# Plans

Design plans for the project, named `<topic>-<YYYY-MM-DD>.md` by the date each was written. Update a plan's **Status** line and this index together when its state changes.

Decisions in force are recorded in [decisions](../decisions/README.md), drawn from plans and reviews as they close; a closing plan's unfinished items move to another plan or a tentative row here, never dropped.

Statuses:

- **Active:** being worked on now.
- **Planned:** agreed direction, not started.
- **Tentative:** worth doing, but the design or priority depends on earlier results.
- **Completed:** done; kept while later plans and tentative rows still build on it.
- **Retired:** closed, with its decisions in decision records or the docs and its leftovers moved, then deleted; git keeps it (see *Retired*).
